🏎️ NineTeen Race (Demo)

Uma Demo Técnica e tributo ao clássico jogo de corrida Road Fighter do NES (1984),
desenvolvido em Python com a biblioteca Pygame.

📝 Sobre esta Demo
Esta é uma versão inicial focada em demonstrar a lógica central do jogo: movimentação, spawn
de inimigos e sistema de colisão. O objetivo é simples, mas desafiador: chegue o mais longe 
possível desviando do tráfego intenso na pista. Assim como no original, a precisão e os 
reflexos são a chave para a sobrevivência!

✨ Funcionalidades Implementadas
-Tráfego Dinâmico: Carros com diferentes padrões de velocidade e IA de desvio.

-Eventos de Acostamento:: Inclusão de viaturas de polícia no acostamento.

-Animação de Explosão: Sequência de frames personalizada ao colidir com qualquer entidade.

-Dificuldade Progressiva: O ritmo de surgimento dos carros aumenta conforme o seu score.

-HUD Experimental: Interface básica com placar e mensagens de status (Pausa/GO).

🕹️ Como Jogar (Demo)

1 - Certifique-se de ter o Python instalado.

2 - Instale o Pygame:
      pip install pygame
      
3 - Execute o jogo:
      main.py

🎮 Controles:

Setas / A-W-D: Movimentam o veículo.

ESC: Pausa a simulação.
